# 👻 >_ ghosttyssh

A companion CLI for the Ghostty (https://ghostty.org) terminal emulator to make SSH easy: automatically syncs Ghostty's terminal capabilities to remote hosts so everything renders correctly, and lets you bookmark, browse, and jump into your servers with a nice TUI. No more broken colors, garbled output, mouse dumping, or typing out long hostnames.

## getting started

```
./setup.sh
```

## uninstall

```
pipx uninstall ghosttyssh
```
